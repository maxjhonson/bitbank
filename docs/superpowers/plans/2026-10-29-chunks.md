# Chunks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user group jokes into a reusable, ordered chunk that drops into a set as one block, with per-set skipping of individual jokes.

**Architecture:** A new `chunks` Dexie table plus a discriminated `SetItem` union (`kind: 'joke' | 'chunk'`) nested in `ComedySet.items`. Pure domain helpers (`resolveChunk`, `breakApart`, a refactored `setTotals`/`weakSpots`) hold all chunk logic; repo functions wrap them in transactions; UI reads a `SetView` whose rows are a union of joke rows and chunk rows. Backup moves to schema version 2 with a migration.

**Tech Stack:** React, react-router, Dexie (+ fake-indexeddb in tests), zod, @dnd-kit, CSS modules, vitest + Testing Library. Check types with `npx tsc -b`; run tests with `npx vitest run <path>`.

**Spec:** `docs/superpowers/specs/2026-10-29-chunks-design.md`

## Global Constraints

- Work on a new branch `feat/chunks` cut from `build/bitbank-v1`. Every commit message ends with the line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- `SUPPORTED_SCHEMA_VERSION` becomes `2`; Dexie gets `db.version(2)`; `SCHEMA_V1` stays untouched.
- A chunk holds only jokes; a joke appears at most once in a chunk (skips are keyed by joke id).
- Chunk time = sum of **ticked** jokes' times; chunk score = unrounded mean of ticked jokes' non-null scores (null if none).
- Segue rule: a chunk joke's segue is spoken only if that joke is ticked and a later joke in the chunk is ticked. A chunk's last row never offers a segue field.
- Set average score and untested count count each ticked joke individually; weak spots treat a chunk as one item using the chunk's score; a chunk with no ticked jokes (or empty) contributes 0 sec and counts as one untested.
- Deleting a joke that is in any chunk is blocked (repo throws, UI lists the chunks). Retiring is not blocked.
- Every new user-facing string goes in both `src/i18n/en.ts` and `src/i18n/es.ts` (the i18n test checks parity).
- Existing tests keep passing; where a signature changes, update the existing tests in the same task.
- Data stays local; no network.

## Review Focus

Most likely to bite, each pinned by a test in the owning task:

1. A v1 backup (set items with no `kind`, no `chunks` key) imports cleanly, and a v1 backup with a set item pointing to a missing joke still imports (dangling item removed) → Task 3.
2. A joke deletion that races a chunk edit: the dialog was opened before the joke was added to a chunk; the repo call must still refuse → Task 2.
3. A chunk with every joke skipped, an empty chunk, and a chunk whose joke was deleted by other means produce no NaN/Infinity and show as untested 0:00 → Tasks 1 and 4.
4. Editing a chunk after a set skipped a joke: reordering keeps the skip, a newly added joke is ticked, removing then re-adding the skipped joke resets it to ticked → Task 2.
5. Duplicating a set keeps chunk items linked to the same chunk with their skips, and adding the same chunk to a set twice is a no-op → Task 2.

### Task 1: Domain types, chunk helpers, totals refactor

**Files:**

- Create: `src/domain/chunks.ts`, `src/domain/chunks.test.ts`

**Interfaces:**
- Produces (types.ts): `Chunk { id; title; items: { jokeId: string; segue?: string }[]; notes: string; createdAt; updatedAt }`; `JokeSetItem { id; kind: 'joke'; jokeId; role?; segue? }`; `ChunkSetItem { id; kind: 'chunk'; chunkId; skippedJokeIds?: string[]; role?; segue? }`; `type SetItem = JokeSetItem | ChunkSetItem`; `ComedySet.items: SetItem[]`.

  - `interface ChunkEntry { jokeId: string; segue?: string; spokenSegue?: string; ticked: boolean; sec: number; score: number | null }`

  - `breakApart(item: ChunkSetItem, entries: ChunkEntry[], alreadyInSet: Set<string>, newId: () => string): JokeSetItem[]`
- Produces (derive.ts): `interface ResolvedItem { itemId: string; sec: number; score: number | null; jokeScores: (number | null)[] }`; `setTotals(set: Pick<ComedySet,'targetSec'|'bufferSec'>, items: ResolvedItem[])` returning the same shape as today; `weakSpots(items: ResolvedItem[]): string[]` returning item ids.

  - `resolveChunk ignores jokes missing from the map`.
  - `resolveChunk with all jokes skipped` → `sec 0`, `score null`, `tickedCount 0`; same for an empty chunk. No NaN.
  - `spokenSegue only when a later joke is ticked`: segues on a,b,c; skip `c` → a has `spokenSegue`, b's is undefined (nothing ticked after it), c's undefined; skip `b` → a keeps its segue.
