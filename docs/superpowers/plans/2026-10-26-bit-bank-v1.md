# Bit Bank v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Bit Bank, a local-first React app where a comedian writes jokes once and assembles them into timed sets, with safe export/import.

**Architecture:** Vite + React + TS SPA. Dexie/IndexedDB is the only store; all DB and backup code lives in `src/db` and `src/backup`; components use hooks from `src/db/hooks.ts`. Pure derived-value math lives in `src/domain/derive.ts`.

**Tech Stack:** Vite, React 18, TypeScript strict, React Router, Dexie + dexie-react-hooks, Zod, @dnd-kit/core + @dnd-kit/sortable, vite-plugin-pwa, Vitest + React Testing Library + fake-indexeddb, CSS Modules.

**Spec:** `docs/SPEC.md` (copy of the product spec; binding authority). Visual reference: `docs/mockup.pdf` (view with Read, `pages` param).

## Global Constraints

- Vite + React 18+ + TypeScript `strict`; CSS Modules (chosen once, used everywhere); app lives at the repo root.
- Components never touch IndexedDB/Dexie directly; only `src/db` and `src/backup` do. Components get data via hooks in `src/db/hooks.ts` (`useLiveQuery`).
- Times stored as integer seconds, displayed `m:ss`. Every record has `id` (`crypto.randomUUID()`), `createdAt`, `updatedAt` (ISO strings). Settings `id` is `'settings'`.
- Dexie schema v1 exactly: `jokes: 'id, status, *tags, updatedAt'`, `performances: 'id, jokeId, date'`, `sets: 'id, date, updatedAt'`, `ideas: 'id, createdAt'`, `settings: 'id'`.
- Data model types exactly as in spec section "Data model" (Joke, Performance, ComedySet, Idea, Settings; `JokeStatus = 'draft'|'working'|'tight'|'retired'`). Defaults: `wordsPerMinute` 150, `backupReminderDays` 7, `bufferSec` 60.
- Tags: lowercase, no `#`, trimmed, de-duplicated.
- Design tokens exactly as spec "Design tokens" in `src/styles/tokens.css`; times and scores use `--font-mono`; touch targets ≥ 44px; contrast ≥ 4.5:1; every control a real `<button>/<a>/<input>` with a label; icon-only buttons have `aria-label`; layouts work at 360px wide.
- Routes: `/`, `/jokes/:id`, `/sets`, `/sets/:id`, `/sets/:id/stage`, `/notebook`, `/settings`.
- Backup file: `{ app:'bitbank', schemaVersion:1, exportedAt, counts:{jokes,performances,sets,ideas}, data:{jokes,performances,sets,ideas,settings} }`, 2-space indent, filename `bitbank-backup-YYYY-MM-DD-HHmm.json`.
- Language: English and Spanish both supported (owner's answer to open question). All user-visible strings go through `useT()` from `src/i18n`; every key exists in both `en` and `es`.
- Score input is a 1–5 laugh rating (owner's answer). Stored `Performance.score` is `rating * 2` (0–10 scale, per data model); all displayed scores, thresholds (score ≥ 7, weak spot 1.5) use the stored 0–10 scale; the log UI shows/edits the 1–5 rating.
- Rehearsals (performance with `venue === REHEARSAL_VENUE` = `'Rehearsal'`) never count toward joke time or score (owner: "I can set the time manually").
- Out of scope: Google Docs import, cloud sync, accounts, audio.
- Tests run with `npm test` (vitest run, jsdom, `fake-indexeddb/auto` in setup). Each task ends with `npm test` and `npx tsc --noEmit` green. Commit messages end with the line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

- Joke with empty setup/punchline/tag lines or `wordsPerMinute` of 0 or garbage: time is 0 (or sane), never NaN/Infinity. (Task 3)
- Route to a nonexistent joke/set id, or a set item whose joke was deleted: friendly not-found / skipped row, no crash. (Tasks 5, 9)
- Navigating away or closing within the 800 ms autosave debounce must not lose the edit. (Task 5)
- Import of an empty file, non-JSON text, or JSON with unknown/extra fields or duplicate ids: clear message, database unchanged. (Task 6)
- Set with zero items, `targetSec` 0, or fewer than 3 items: no divide-by-zero in the progress bar, no weak spots reported. (Tasks 3, 9)

### Task 3: Derived values (`derive.ts`)

**Files:**
- Create: `src/domain/derive.ts`
- Test: `src/domain/derive.test.ts`

**Interfaces:**
- Consumes: types from Task 2.
- Produces:
  - `type TimeSource = 'measured'|'manual'|'estimated'`
  - `jokeTime(joke: Joke, perfs: Performance[], wpm: number): { sec: number; source: TimeSource }`
  - `jokeScore(joke: Joke, perfs: Performance[]): number | null` (one decimal)
  - `scoreTrend(perfs: Performance[]): number | null`
  - `runCount(perfs: Performance[]): number`
  - `setTotals(set: ComedySet, jokes: Map<string, {sec:number; score:number|null}>): { jokesSec: number; totalSec: number; remainingSec: number; avgScore: number | null; untestedCount: number; over: boolean }`
  - `weakSpots(set: ComedySet, scores: Map<string, number|null>): string[]` (item ids)

Rules (spec "Derived values", with these pins): performances are sorted by `date` then `createdAt` ascending; "last 5" = the 5 latest. Rehearsal performances (`venue === REHEARSAL_VENUE`) are excluded from time, score, trend and runs. Time: `manualTimeSec` if set (even 0) → `manual`; else mean `durationSec` (rounded) of performances having one → `measured`; else `round(words / wpm * 60)` → `estimated`, where words = whitespace-split tokens of setup + punchline + every tagLine text, and `wpm <= 0` or non-finite falls back to 150. Score: mean of last 5 scores, else `manualScore`, else null. Trend: needs ≥ 6 performances; mean(last 5) − mean(up to 5 before them). `setTotals`: `totalSec = jokesSec + bufferSec`; items whose jokeId is missing from the map are skipped; `untestedCount` = items with null score; `avgScore` null when none scored. `weakSpots`: only items at indices `1..n-2` (so none when n < 3), with non-null score ≤ `avg − 1.5`, where avg is the set average over scored jokes.

- [ ] **Step 1: Write failing tests**, one `describe` per row of the spec's derived-values table, including: empty joke → `{sec:0, source:'estimated'}`; `wpm: 0` falls back; single performance; manual time `0` wins; rehearsal excluded from time/score/runs; score rounding to one decimal; trend null at 5 perfs, defined at 6; weak spot boundary exactly 1.5 below flagged, 1.4 not; first/last slot never flagged; zero-item set → totals 0 + buffer, no NaN; `over` true when `totalSec > targetSec`.
